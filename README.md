# AdDeck downloads

The public download place of AdDeck, the free app from LSALab that makes marketing creatives on your own computer. The app's own code is not here.

- Download: https://lsalab.dev/download/addeck (it picks the file for your system).
- What AdDeck does and how to use it: https://lsalab.dev/addeck
- Every version is a release on this page, with one zip per system: Windows, Mac with Apple silicon, Linux (x64). Each zip carries its own README with the install steps.
- `releases/latest.json`: the newest release. A copy of AdDeck running an older version reads it once a day and shows a notice with the link. Nothing is downloaded or installed by itself.
- `TERMS.txt`: the terms of use, the same text that comes in every zip.
